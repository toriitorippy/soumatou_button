# 走馬灯ボタン 🎲

日本の公的統計データに基づく、ブラウザ完結型の人生シミュレーションゲーム。  
生まれた瞬間から死ぬまでの人生を、ターニングポイントの選択とランダムなカルマイベントで体験する。

---

## プレイ方法

1. ブラウザで `index.html` を開く（ローカルサーバー推奨）
2. 「人生をはじめる」ボタンを押す
3. 親ガチャ結果を確認し、スタート
4. 自動進行する人生を見守りながら、ターニングポイントで選択肢を選ぶ
5. 死亡後に「走馬灯」シーンと人生スコアを確認
6. 「人生やり直し」で何度でも転生可能

## 主な仕様

### 初期ガチャ（親ガチャ）
- **所得層**：低所得（30%）/ 中所得（50%）/ 高所得（18%）/ 富裕層（2%）
- **出生地**：全47都道府県・実人口比率に基づく重み付き抽選
  - 誕生モーダルに「xx県に生まれる確率：X.X%」を表示
- **性格タイプ**：6種（勉強家 / 体育会系 / 芸術家 / 社交的 / 野心家 / のんびり）
  - 誕生時は「？？？」として伏せられ、**13歳のタイミングで自動開示**
- **初期ステータス**：知性 / 努力値 / 幸運 / 容姿 / 学力 / 運動（正規分布）

### 自動進行
- 1年ごとに自動進行（デフォルト1800ms／年）
- SPEEDボタンで 600 / 1200 / 2000ms / 一時停止 を切り替え可能
- カルマ・ターニングポイント発生時は500ms〜のタメ後にモーダルが出現

### ターニングポイント（イベント選択）
- 人生の重要な分岐を選択形式で提示
- 利用可能な選択肢のみ表示（条件不足は最大1件まで表示、それ以外は非表示）
- 最大5件に絞り込み、全選択肢が画面内に収まるよう高さを自動調整
- 成功率は性格ボーナスが反映され、結果はダイスアニメーションで演出

主なターニングポイント（全36種）：
- 幼稚園 / 小学受験 / 初恋 / 中学・高校の進路 / 就職（全職種から選択）
- 結婚 / 副業 / 海外移住 / 起業 / セカンドキャリア など

### カルマイベント（83種）
- 毎年ランダムに発生（各イベントは独立した確率で抽選）
- カテゴリ：健康 / 労働 / 恋愛・家族 / 経済 / 災害 / 社会
- **大災害・パンデミックはクールダウン制**（一度発生後15〜25年は再発しない）
- 年間の重大バッドイベントは最大2件に制限

### 死亡率
- 厚生労働省の生命表に準拠した年齢別死亡率（‰）を使用
- 健康・ストレスは乗率として死亡確率に反映（若年層への影響は軽微）
- 普通にプレイすれば60〜70代まで高確率で到達

### 所持金
- 22歳未満：家庭の所得層に応じたお小遣い（0〜3万円/年）が少しずつ増加
- 就職後：年収の約12%が毎年貯蓄される
- 無職の成人：生活費として5万円/年が減少

### 人生スコア・評価
| グレード | 説明 |
|----------|------|
| S（90点〜） | 伝説的な人生 |
| A（75〜） | 充実した人生 |
| B（60〜） | 平均的な人生 |
| C（45〜） | 苦労が多かった |
| D（30〜） | 厳しい人生 |
| F（〜30） | 波乱万丈な人生 |

スコア配分：長寿35点 / 資産30点 / 精神20点 / 健康15点

## 画面構成

```
┌──────────┬──────────────────────┬──────────┐
│          │    バナー画像         │          │
│ 人生カルテ│   （ライフステージ）  │ 人生の歩み│
│          ├──────────────────────┤  タイム  │
│ ステータス│    ログ（中央）       │  ライン  │
│          │                      │          │
│やり直し  ├──────────────────────┤          │
│ ボタン   │  SPEEDボタン          │          │
└──────────┴──────────────────────┴──────────┘
```

- **左カラム**：人生カルテ（年齢 / 所持金 / 健康・ストレスバー / 各種ステータス）
- **中央カラム**：人生ログ（カルマは赤枠、TP は紫枠でハイライト）
- **右カラム**：人生の歩みタイムライン（逆順で最新が上）

## データファイル

| ファイル | 内容 |
|----------|------|
| `data/statistics.json` | 死亡率・所得層・性格・パートナー情報 |
| `data/prefectures.json` | 全47都道府県・人口比重み・主要都市 |
| `data/turningPoints.json` | ターニングポイント36種 |
| `data/karmaEvents.json` | カルマイベント83種 |
| `data/jobs.json` | 職種一覧（年収・採用率・必要ステータス） |
| `data/schools.json` | 学校一覧（中学・高校・大学・専門） |
| `data/companies.json` | 企業名一覧 |
| `data/narratives.json` | 年齢別ナラティブテキスト |

## ローカル実行

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

ブラウザで `http://localhost:8080` を開く。  
`file://` 直接開きでは ES Modules の CORS エラーが出るため、ローカルサーバーが必要。
